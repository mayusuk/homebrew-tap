# mayusuk/homebrew-tap

Homebrew formulas for [agent-loop](https://github.com/mayusuk/agent-loop) and its starter handlers, [agent-loop-claude](https://github.com/mayusuk/agent-loop-handlers).

## Install

```bash
brew install mayusuk/tap/agent-loop
agent-loop sign          # macOS: after installing and after every brew upgrade
agent-loop version
```

On macOS, `agent-loop sign` signs the installed binary with your self-signed `agent-loop code signing` certificate (created in your login keychain the first time), so the Keychain items keep trusting agent-loop across upgrades. Homebrew can't do this for you: its post-install step runs in a sandbox that can't reach your login keychain. See "Keychain trust" in the [getting-started guide](https://github.com/mayusuk/agent-loop/blob/main/docs/GETTING-STARTED.md).

The starter handlers run Claude Code, so install Claude Code and log in first:

```bash
brew install mayusuk/tap/agent-loop-claude
agent-loop-claude version
```
